THE PROCESS

Many Questions, As Many Answers.

◈

Upload a file

First a flie is uploaded, then it is broken into several chunks.

◉

Vector Embeddings

The chunks are then taken and converted into vector Embeddings and for this project this is done via Hugging Face.

↗

Ask A Question

When the user asks a question that question is then taken and broken into tokens.

✓

Reply

Those tokens are then taken and run through a similarity search with the previously made vector embeddings and the response with the highest score is given to the user
